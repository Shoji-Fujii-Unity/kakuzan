# カク算 KAKUZAN — 四則演算 × マス目のパズル

[English README](README_EN.md)

たす・ひく・かける・わる の四則演算をヒントに、マス目へ数字をはめ込む論理パズル（ケンケン／calcudoku 系）を1ファイルで遊べるようにしたものです。

## 起動方法

| 端末 | 手順 |
| --- | --- |
| PC | `index.html` をダブルクリックするだけ |
| Android | ファイルを端末にコピーし、Chrome で開く（ホーム画面に追加するとアプリのように全画面表示できます） |
| iPhone | ファイルを「ファイル」アプリに保存し、Safari で開く → 共有 → ホーム画面に追加 |
| LAN で共有 | PC で `python -m http.server 8000` などを立てて、スマホから `http://<PCのIP>:8000/` を開く |

初回はネット接続があると CDN からライブラリとフォントを取得します。ネットが無い場合は内蔵のフォールバックでそのまま遊べます（音=WebAudio / 多言語=内蔵辞書 / 保存=localStorage）。

## ルール

1. 盤面に **1〜N** を、どの行にもどの列にも1回ずつ入れます。
2. 枠（ケージ）左上が計算ヒント。`7+` なら枠内の合計が7、`12×` なら積が12。
3. `3-` は2マスの差、`2÷` は2マスの割り算の結果。`5` だけならそのマスが5。
4. `+` と `×` は3〜4マスの枠もあり、`-` と `÷` は2マスの枠だけ。
5. 解は常に **ただ1つ**（生成時にソルバで一意性を検証しています）。

## 機能

- 4×4 / 5×5 / 6×6、ステージ制（クリアで解放）＋ 今日のチャレンジ（日付で全端末共通の1問）
- 難易度は実際の盤面を採点して ★ 表示（確定マスの多さ＝易しい、大きい枠・÷・−＝難しい）
- タップ入力、なぞって連続入力、候補メモ、ヒント、判定、Undo、一時停止
- キーボード操作（1〜9 / 矢印 / Backspace / N / H / C / U / Esc）
- サウンド ON/OFF（Tone.js。タップ音・誤答音・クリアファンファーレ）
- 明るい／暗いテーマ
- 言語：日本語・English·中文·한국어·Español（自動判定、設定から切替）
- 記録：タイム・ヒント数・まちがい数・星（ヒント0〜2で星が増える）

## セーブデータ

この端末のブラウザ内にだけ保存されます（サーバーへ送信しません）。

- `kakuzan.settings.v1` 設定
- `kakuzan.progress.v1` 進行・記録・統計
- `kakuzan.game.v2.<サイズ>.<モード>` 遊び中の盤面（サイズとモードごとに1枠。今日のチャレンジがステージの途中経過を上書きすることはありません）

設定画面の「セーブデータを削除」で全て消せます。保存できない環境では設定画面にその旨を表示します。

## 読み込んでいるライブラリ（CDN）

- i18next 23 — 多言語
- localforage 1.10 — ローカル保存（IndexedDB、だめなら localStorage）
- Tone.js 14 — サウンド
- Google Fonts（M PLUS Rounded 1c）

## 開発メモ

`node --check` による構文チェックと、生成ロジックのテスト（解の一意性を別実装の総当たりソルバと突き合わせる）を実施済みです。
